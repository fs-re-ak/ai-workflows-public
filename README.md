# ai-workflows-public

Workflows maintained by RE-AK Technologies Inc. for data analysis. They give an agent a default method when someone is getting started, or when they ask to follow this method. A plan the project already has takes priority.

## Public contents

This repository holds instructions and nothing else. It does not hold recordings, exports, identifiers, credentials, or client deliverables. Examples use schematic names such as `session-example`.

## Workflows

| Workflow | What it standardizes |
|---|---|
| [Analysis steps](workflows/analysis-steps.md) | Organize, process, annotate (temporal and spatial), explore, and report. Keep a journal in the data project. |
| [Data project layout](workflows/project-layout.md) | Where source data, the journal, reference material, analysis outputs, and the deliverable go |

## Use with an agent

Link this repository into the data project where it should apply. The steps for Claude Code and Cursor are in [SETUP.md](SETUP.md). Install it for that project. A user-wide install would attach the method to unrelated work.
